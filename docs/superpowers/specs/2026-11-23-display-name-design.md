# Отображаемое имя участника Comms

При первом подключении пользователь вводит отображаемое имя. После входа каждый видит своё имя и имена остальных подключённых участников. При повторном входе используется сохранённое имя. В списке рядом со своей строкой пользователь может выбрать «Изменить имя». Успешное изменение видно всем подключённым участникам и сохраняется для следующего входа.

Пробелы по краям удаляются. Пустое имя отклоняется. Одинаковые имена допустимы, строки участников различаются по идентификатору подключения.

## Рассмотренные варианты

- Запрашивать имя только при первом входе и редактировать его в списке. Выбран этот вариант, чтобы не добавлять шаг при повторном подключении.
- Показывать заполненное поле имени при каждом входе. Это позволяло бы изменить имя до подключения ценой дополнительного поля при каждом входе.

## Зависимость и допущение для плана

В текущем Comms есть каркас React и маршрут Ktor для проверки состояния. Список участников и сигналинг описаны в [дизайне этапа 1](2026-11-22-stage-1-voice-design.md) и нужны для этой функции.

В Comms пока нет аккаунтов. Для первой версии согласовано сохранять имя в профиле браузера через localStorage. Другой профиль или устройство попросит ввести имя при первом входе.
